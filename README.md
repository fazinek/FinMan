# FinMan

General-purpose personal finance web app for public use.

- Multiple months and historical transactions
- Customizable 50/30/20 budgeting
- Income and expenses
- Money lent / borrowed and repayments
- Multiple savings goals with add/remove funds
- JSON export/import backup
- Offline PWA support
- No bank connection

## GitHub Pages
Upload everything in this folder to the repository root. Then open Settings → Pages → Deploy from a branch → main → /(root).

Finance data is stored locally in the browser. Export a backup regularly if the data is important.
